**Atue como** um analista de segurança cibernética e de experiência do cliente.

**Sua tarefa é analisar** comentários de clientes bancários idosos **sobre** a utilização dos aplicativos **para identificar** as principais falhas de segurança e vulnerabilidades.

**Contexto:** Estou trabalhando com feedbacks de clientes bancários relacionados à segurança digital dos idosos. O resultado será usado por uma equipe de segurança cibernética para apoiar melhorias estruturais nos aplicativos e reforçar a proteção do idoso. A análise precisa gerar resultados claros, organizados e de aplicação viável.

**Dados disponíveis:** A base contém data dos comentários, reclamações descritivas, recomendações dos usuários e estatísticas de crimes cibernéticos associados.

**Instruções de análise:**
* Classifique os feedbacks por temas, nível de urgência, tipos de fraudes e crimes cibernéticos relatados.
* Identifique os principais padrões, problemas, elogios e oportunidades.
* Aponte evidências nos dados fornecidos.
* Sugira ações práticas para a equipe de segurança cibernética.

**Formato da resposta:** A entrega deve conter um resumo técnico, uma lista de insights e recomendações práticas.

**Restrições:**
* Use apenas os dados fornecidos.
* Não invente números, causas ou conclusões.
* Não exponha dados pessoais ou sensíveis.
* Informe limitações quando os dados não forem suficientes (se houver informação insuficiente, indique a limitação).
* Use linguagem técnica.
